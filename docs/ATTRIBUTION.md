## Вклад этого комплекта

Этот комплект не претендует на авторство UEFI-эксплойта или алгоритмов GSP/SEC2. Содержит только оригинальную обвязку:

1. Преобразование upstream-функции обнаружения GPU в две версии с выбором совпадения ordinal 0/1.
2. Отдельную сборку двух EFI-приложений без перезаписи рабочего EFI.
3. Последовательный запуск через GRUB и `--return-to-grub`.
4. systemd oneshot для автоматической настройки `grub-reboot`.
5. Практическую документацию и измерения с конкретного стенда.

## Почему здесь нет EFI бинарников и firmware blobs

Двоичные firmware-компоненты и код первоначального EFI получаются из upstream-репозитория. Вопросы лицензирования и прав на включённые firmware blobs нельзя считать автоматически разрешёнными общим `LICENSE` репозитория. Перед публичной публикацией производных **бинарников**, чужих **исходных файлов** или **blobs** требуется отдельная проверка применимых лицензий и copyright-уведомлений. Пользователь собирает firmware локально из upstream.

Не включайте в публичные Issues/логи серийные номера, GPU UUID, имена пользователей, hostname, пути с личными данными и внутренние IP, если это не нужно для диагностики.

Этот файл не является юридическим заключением.
